📘 Guía Rápida: Cargar en Supabase (Android & iPhone) Abrir Supabase Secrets ↗
  1. Generá y descargá: tocá "⚡ Generar VAPID Keys y Descargar Archivos" para bajar supabase-push-secrets.env y db-config.js.
  2. Subí los Secrets a Supabase: en tu proyecto de Supabase andá a Edge Functions → Secrets y cargá las 3 variables de supabase-push-secrets.env (VAPID_PUBLIC_KEY, VAPID_PRIVATE_KEY, VAPID_SUBJECT), o ejecutá por terminal:
    supabase secrets set --env-file supabase-push-secrets.env && supabase functions deploy order-status-push
  3. Activá el Database Webhook en Supabase: andá a Database → Webhooks → Create a new hook, elegí la tabla public.order_status, eventos INSERT y UPDATE, y tipo Supabase Edge Functions → order-status-push.
  4. Actualizá tu web pública: reemplazá web-pwa/db-config.js con el archivo descargado (o pegalo en el Secret DB_CONFIG_JS de GitHub) y hacé Push.
  5. Habilitá alertas en cada dispositivo:
    • Android (Chrome): abrí la tienda online, tocá 🔔 Activar alertas y aceptá el permiso.
    • iPhone (iOS 16.4+ Safari): abrí la tienda en Safari → Compartir ⬆️ → Agregar a pantalla de inicio, abrí la app desde el ícono instalado y tocá 🔔 Activar alertas.
