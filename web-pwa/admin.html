Configurá web-pwa/firebase-config.js para sincronización en la nube

Ya incluimos la plantilla web-pwa/firebase-config.js en el proyecto, pero todavía tiene claves de ejemplo (YOUR_FIREBASE_*). Seguí estos pasos para conectar pedidos y confirmación de pagos en tiempo real con Firestore:

  1. Abrí Firebase Console (proyecto gen-lang-client-0684931110) → Configuración del proyecto → Tus apps → Web (o ejecutá firebase apps:sdkconfig web --project gen-lang-client-0684931110).
  2. En web-pwa/firebase-config.js, reemplazá YOUR_FIREBASE_WEB_API_KEY, YOUR_FIREBASE_MESSAGING_SENDER_ID y YOUR_FIREBASE_WEB_APP_ID (dejando intacto PIZZA_CLUB_DATABASE_ID).
  3. Si desplegás desde GitHub Actions, pegá ese archivo completo en el secreto de repositorio FIREBASE_CONFIG_JS.
  4. En Firebase Console → Authentication → Settings → Authorized domains, agregá tu dominio web (ej. tu-usuario.github.io) para habilitar el acceso con Google (alejandromoises89@gmail.com).

Mientras tanto, la tienda cliente funciona en modo local (localStorage + WhatsApp) y también podés operar Admin desde la app Android ya vinculada a Firebase.
